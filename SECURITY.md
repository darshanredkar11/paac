# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

We take the security of PAAC seriously. If you discover a vulnerability or security issue, please do **NOT** open a public issue on GitHub.

Instead, please report security vulnerabilities directly to our security team at:
`security@paac.dev`

Please include:
- A description of the issue and potential impact
- Steps to reproduce or proof-of-concept code
- Any proposed remediation if available

We will respond within 48 hours and provide regular updates on remediation progress.
